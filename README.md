## 🛠️ Tools & Environments

- **Proteus 8 Professional**: Schematic Capture & Circuit Simulation (8051, Arduino, Sensors)
- **Keil µVision IDE (C51 / ARM)**: 8051 Assembly & Embedded C development
- **Arduino IDE**: Embedded C/C++ development for sensors & actuators
- **SystemC / C++**: Hardware-Software Co-design, Concurrent Process Modeling, Semaphores & TLM
- **Wokwi Simulator**: Cloud-based embedded systems simulation
